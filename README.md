# 体素東京 · 暮色（Voxel Tokyo at Dusk）

用 Three.js 实现的超大型日式都市体素场景：黄昏天空下，发光高塔、摩天楼群、神社、密集住宅区与环城高架电车交织出"现代包围传统"的城市景观。

## 运行方式

**方式一：离线单文件（最简单）**

直接双击打开项目根目录下的 `体素东京-暮色.html` 即可——Three.js 与全部场景代码已内联，无需安装任何东西、无需联网、无需服务器。

重新生成单文件：

```bash
npm run build:single   # 输出 dist-single/index.html 并复制为 体素东京-暮色.html
```

**方式二：开发模式**

```bash
npm install     # 安装依赖（three + vite）
npm run dev     # 开发模式，浏览器打开 http://127.0.0.1:5173
```

构建与本地预览：

```bash
npm run build   # 输出到 dist/
npm run preview # 预览构建产物
```

页面打开即自动环绕展示全城；可鼠标拖拽旋转、滚轮缩放。

## 技术要点

- 全场景约 43 万体素按 8×8 空间 chunk 合并为约 128 个 InstancedMesh（受光实体 + 自发光分组），手动包围球恢复视锥剔除；自发光材质关闭 tone mapping，霓虹不被 ACES 压灰
- 地面由逐格放置改为行扫描 + 纵向条带合并（119 万 → 7.7 万实例）；暗窗不生成实例；大面积填充使用缩放实例
- 方向光 PCF 软阴影**静态烘焙一次**（`shadowMap.autoUpdate=false`），2048 阴影贴图；帧率低时分级降 pixelRatio 再关阴影
- 电车曲线预采样 512 点查找表，每帧零次 `getPointAt`；每节车厢几何按材质合并（5 节共 10 个 Mesh）；云合并为单个 InstancedMesh 整体循环
- 构建完成后释放体素记录数组；生成使用固定种子的伪随机数，每次打开布局一致

## 项目结构

```
index.html            页面与 HUD（Vite 入口）
vite.config.js        开发/构建配置（输出 dist/）
vite.single.config.js 单文件构建配置（输出 dist-single/ → 体素东京-暮色.html）

src/main.js           渲染器、相机、光照、动画主循环、自适应画质
src/voxel.js          VoxelBuilder（InstancedMesh 合批）
src/ground.js         地面铺装
src/rail.js           5 节编组行驶电车（弧长查找表）
src/sky.js            天空穹顶、星月、远山、夜云
src/tower.js          仿东京塔体素高塔（单体实现）
src/planView.js       ?plan=1 正射俯视贴图
src/rng.js            确定性伪随机

src/city/             城市模型（布局知识唯一出口）
  config.js           全部常量：种子、尺寸、色板、分区
  query.js            CITY 单例：地形/路网/水系/街区/地块管线与 claim 登记
  field.js            格子场与压印（stampRibbon / stampDisc / …）
  geom.js             吸附角度、折线采样、连通域、最大内接矩形
  terrain.js          西高东低台地与高度量化
  water.js            河道、港湾、护岸、桥
  roads.js            轨道环与车站、主干/次干/巷道、道路剖面
  blocks.js           街区提取
  plots.js            宅地划分（临街面、退让）
  districts.js        分区配额与副都心
  viewpoints.js       验收机位与 URL 参数

src/build/            体素建造（placeFromCity）
  index.js            建造入口：placeFromCity / buildRailCurveFromCity
  palette.js          墙/屋面/窗/霓虹/道具色板
  claimUtil.js        占地登记、行道树
  heightField.js      高度场
  massing.js          楼体体量
  facade.js           立面开窗
  roofscape.js        屋顶与退台腰线
  districts.js        按分区落楼与绿地
  landmarks.js        三大地标（东京塔/天空树/都厅）
  street.js           路灯、电线杆、贩卖机、信号灯、车辆
  rail.js             高架环线、车站体素

tests/                node:test 规格测试（npm test）
docs/                 规格与阶段文档

```

公开版省略历史原型和探针目录。
